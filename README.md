# Витрина Exsul

Сайт программы: главная, издания, загрузка, «как устроено» и новости.
Собирается сам по себе и ничего из программы не тянет — версии и ссылки на
скачивание он берёт из репозитория обновлений.

---

## Как посмотреть сайт у себя

Запустить **`ПОСМОТРЕТЬ-САЙТ.bat`**.

Он сам проверит Node.js, поставит зависимости при первом запуске и откроет
браузер. Правки видны сразу: поправили текст — вкладка обновилась.
Закрыть — Ctrl+C или крестиком окна.

Если Node.js не установлен, файл так и скажет и даст ссылку.

---

## Как выложить сайт в интернет

Запустить **`ОПУБЛИКОВАТЬ-САЙТ.bat`**.

Он сначала проверит, что сайт собирается (выкладывать сломанное нельзя),
и только потом отправит исходники в репозиторий сайта. Дальше GitHub соберёт
и выложит его сам за минуту-две.

Смотреть результат: <https://schreiry.github.io/Exsite/>
Ход сборки: <https://github.com/Schreiry/Exsite/actions>

---

## Что настраивается один раз

### 1. Репозиторий сайта и GitHub Pages

1. Открыть <https://github.com/Schreiry/Exsite> → **Settings** → **Pages**.
2. В разделе **Build and deployment** → **Source** выбрать **GitHub Actions**.
   (Не «Deploy from a branch» — сборкой занимается наш файл `deploy.yml`.)
3. Всё. Первая публикация случится при первой отправке.

### 2. Приём заявок на лицензию

Сайт статический — своего сервера у него нет, поэтому письмо он отправляет
через бесплатный приёмник форм.

1. Открыть <https://web3forms.com>, ввести свою почту, нажать **Create Access Key**.
2. Ключ придёт на почту — строка вида `a1b2c3d4-...`.
3. Открыть `src/lib/content/orderForm.ts` и вставить ключ в одну строку:

   ```ts
   export const ACCESS_KEY = 'сюда-ключ-из-письма';
   ```

4. Опубликовать сайт заново.

**Пока ключа нет, форма не врёт и не теряет заявку**: она открывает почтовую
программу с уже заполненным письмом, и человек отправляет его сам.

### 3. Свой домен, когда он появится

1. Купить домен и направить его на GitHub Pages (в настройках домена —
   записи, которые покажет GitHub на странице Pages).
2. В `.github/workflows/deploy.yml` удалить две строки:

   ```yaml
   env:
     SITE_BASE: /Exsite
   ```

3. Создать файл `static/CNAME` с одной строкой — вашим доменом.
4. Опубликовать сайт заново.

Ни одну страницу править не придётся: адрес живёт в одном месте.

## Что где лежит

| Что менять | Файл |
| --- | --- |
| Цены и состав изданий | `src/lib/content/editions.ts` |
| Тексты сайта (русский и английский) | `src/lib/i18n.ts` |
| Новости | `src/lib/content/posts.ts` |
| Откуда берутся версии программы | `src/lib/content/releases.ts` |
| Приём заявок | `src/lib/content/orderForm.ts` |
| Снимок программы на главной | положить `static/app-screen.png` |

Цены и возможности живут **в одном файле**: карточки изданий и таблица
сравнения строятся из него, поэтому разойтись между собой не могут.
